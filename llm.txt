# podras — llms.txt

podras ("project status, distilled") is a deterministic, per-repo CLI that answers "what's happening in this project?" for humans returning cold and for AI coding agents. It derives status from evidence that already exists — beads tracker, openspec changes, git history, whisper session notes — and layers explicit human intent (`focus`/`park`) on top. Status is a projection of evidence plus intent, never a hand-maintained document.

## Envelope contract

- `podras brief --json` emits a typed JSON envelope: `schema_version: "brief.v1"`, per-source freshness (`sources[]` with `observed_at`), curation timestamps, `staleness: fresh|stale|unknown`, `truncation{}`, `head_sha`/`source_hash`, explicit unknowns. A contract, not a prompt.
- Typed enums, bounded sections with deterministic order (1 focus, 5 recent/blockers/next/parked, all warnings). Never silently truncate; never turn unknown into green; never infer focus from priority or progress from commits.
- `--as-of YYYY-MM-DD` pins the observation instant; identical inputs produce identical output. The committed `--write` render differs from on-demand only in `generated_at`.
- The published JSON Schema: `podras schema`.

## Key commands

- `podras init` — idempotent scaffold of `.podras/curation.toml` + AGENTS.md managed block (house rules for agents: run `brief --json` first; never edit `.podras/*.toml`).
- `podras brief [--json] [--write] [--as-of DATE] [--out-dir DIR]` — nine fixed sections: purpose, focus, in flight, blocked, next, parked, recent, health, sources & freshness. `--write` commits `BRIEF.md` + `BRIEF.json`.
- `podras roadmap [--json] [--write] [--as-of DATE]` — separate why-lens (identity, bets, no-gos) from hand-written `.podras/roadmap.toml`. `--write` emits `ROADMAP.md` + `ROADMAP.json` (full envelope with the `roadmap` object attached).
- `podras focus <ID>` — select-or-replace curated focus (cap N=1 by construction).
- `podras park <ID> --reason ... --resurface <DATE|event:NAME>` — park with a mandatory resurface trigger.
- `podras harvest [--json] [--as-of DATE]` — surface mismatch candidates, zero state changes; curation beats inference.
- `podras schema` — emit the brief JSON Schema.

## State files

`.podras/curation.toml` (intent: purpose-lite, focus/parked entries, human health verdict, `publish_whisper` opt-in) and `.podras/roadmap.toml` (why-lens: `[identity]`, `[[bets]]`, `[[no_gos]]`; closed enums `horizon: now|next|later`, `status: shaping|committed|building|deferred|shipped|killed`, `enforcement: automated|human_review`). Both git-committed, human-owned; agents never edit them. Missing roadmap file ⇒ brief carries no `roadmap` object; malformed file ⇒ brief degrades with one warning, `roadmap` command hard-errors.
